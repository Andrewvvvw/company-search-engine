# Поиск компаний

Навык для ChatGPT и Python-скрипт для хранения результатов и создания Excel. Место, отрасль, количество компаний и нужные поля задаются каждым запросом.

ChatGPT ищет в интернете и читает источники. Скрипт проверяет заполненные данные, отсеивает дубли, хранит историю задачи и собирает книгу.

## С чего начать

- [Установка и запуск](docs/INSTALL.md) — как запустить скрипт и собрать ZIP навыка из исходников.
- [Что проверяют тесты](docs/TESTING.md) — сценарии и команды проверки.

## Структура

| Папка | Что в ней |
| --- | --- |
| `skills/company-search-agent/` | Навык, его инструкции и основной скрипт |
| `examples/` | Два примера запросов и вымышленные данные для тестов |
| `tests/` | Тесты основного скрипта |
| `tools/` | Скрипты подготовки демо и полного комплекта для релиза |
| `docs/` | Документация к исходникам |

Сгенерированные карточки, книги, отчёты и ZIP исключены из Git. Для запуска скрипта и тестов заранее созданные файлы не нужны.

После установки навыка в ChatGPT можно написать:

> Найди 3 стоматологические клиники Алматы. Нужны название, адрес, телефон и сайт. Одна строка на юридическое лицо. Результат — один Excel.

Для продолжения в другом чате карточка должна быть сохранена в хранилище, доступном этому чату. После окончания запуска поиск в фоне не идёт.
