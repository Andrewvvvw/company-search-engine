# Установка и запуск

1. Если в аккаунте есть **Plugins → Skills → Create → Upload from your computer**, загрузить zip из `Release`.
2. Дождаться установки.
3. Открыть новый Work, через ввод `@` выбрать `company-search-agent`.
4. Отправить запрос, например:

> Найди 3 стоматологические клиники Алматы. Нужны название, адрес, телефон и сайт. Одна строка на юридическое лицо. Результат — один Excel.
