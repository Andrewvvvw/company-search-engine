# Постоянное хранение и возобновление

Локальный JSON нужен скрипту в текущем запуске. Для «Продолжи КОД» в новом чате необходим отдельно проверенный встроенный постоянный способ хранения. Не считать sandbox, историю диалога или память гарантированным хранилищем.

## Pages, когда доступны

1. Найди Page по точному коду `CSA-...`. При нескольких карточках проверь request и все ревизии; не выбрасывай найденные версии.
2. До записи новой карточки прочитай существующую Page и инструкции доступа. Сохраняй полный JSON карточки в fenced `json` блоке либо как доступное вложение и короткий статус с кодом и ревизией. Большие задачи дели на карточку-индекс и дочерние части журнала с manifest/hash: загрузить нужно все части.
3. Перед каждой записью перечитай последнюю ревизию. При отличиях выгрузи её, выполни `merge`, затем запиши объединённую карточку с доступным optimistic guard. Если запись конфликтует, повтори read/merge; не заменяй всю Page устаревшей копией.
4. После успешной записи прочитай Page, сверь code, revision, digest и число событий. Только тогда сообщай «сохранено». При неопределённом исходе записи сначала выясни её результат; не создавай новую Page наугад.
5. Проверь в действительно новом чате: `Продолжи КОД` должен найти карточку и выполнить следующий участок. Чтение Page вторым вызовом в том же чате подтверждает сохранность, но не прохождение этого теста.

Используй актуальные инструменты Pages текущей сессии; не выдумывай их имена. Соблюдай действующие правила Pages. Карточка приватная, если пользователь не задал иной доступ. Не менять sharing, не подключать новые внешние сервисы только ради хранения.

## Если постоянное хранение отсутствует

Запиши наблюдаемое ограничение и согласуй границы: текущий запуск с явной резервной копией карточки или ожидание доступной поверхности. Резервная копия позволяет ручное восстановление, но не соответствует автоматическому возобновлению только по коду. Не заявляй полную совместимость. Не выдавай промежуточный Excel вместо карточки.

## Проверка установки

В аккаунте заказчика: Plugins → Skills → Create → Upload from your computer → ZIP. Дождись завершения сканирования и статуса установленного навыка. Меню, права и доступность могут отличаться. Сверь официальную документацию на момент установки.

Проверь новый Work, новый обычный Chat в браузере и Android отдельно: автоматическое применение обычной фразой, явный вызов через селектор `@`/название, поиск, выполнение скрипта, сохранение карточки, скачивание `.xlsx`. Установка исходников в Codex не доказывает установку в ChatGPT. Если standalone ZIP не распространяется на нужную поверхность, проверь поддерживаемую упаковку skill в plugin; это отдельная фактическая проверка, не обещание.
